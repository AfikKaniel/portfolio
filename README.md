# Afik Kaniel — portfolio

One-page personal site, served by GitHub Pages at https://afikkaniel.github.io/portfolio/

Plain HTML, CSS and JavaScript. No build step and no dependencies.

- `index.html` — the page
- `assets/css/site.css`, `assets/js/site.js` — styles and the scroll scenes
- `assets/js/light.js` — the WebGL liquid light behind the page (off with Reduce Motion; a still gradient stands in)
- `assets/fonts/` — Geist, served from the site (one variable Latin file; SIL Open Font License in `OFL.txt`)
- `assets/img/` — photo, company logos, App Store images
- `assets/video/` — compressed screen recordings (H.264) and their poster frames
- `assets/og.png` — link preview image for LinkedIn, WhatsApp and X

Preview locally:

```bash
python3 -m http.server 8765
```
